# Splendor Web Game

A web-based implementation of the Splendor board game, developed using Python.

## Overview

This project aims to recreate the Splendor board game as a web application where a human player can compete against AI opponents.

The project is being developed as a personal portfolio project to improve my software development skills and apply concepts learned during my Computer Science studies.

## Tech Stack

- **Backend:** Python, FastAPI
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **Testing:** Pytest
- **Version Control:** GitHub
